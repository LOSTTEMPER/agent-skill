# codex上高速

让 Codex 在指定项目中配置 hook，将附带文件加载到 developer 上下文。技能只说明需要完成什么，具体实现和操作步骤由执行技能的 Codex 根据当前系统与客户端决定。

安装本仓库的 `codex-highway/` 技能后，在目标项目中告诉 Codex：

> 使用 $codex-highway 为当前项目配置 codex上高速。请根据我当前的系统和 Codex 环境完成配置，不要预读附带文件正文，并告诉我如何信任项目和 hook。

请仅在 **5.6 Sol（`gpt-5.6-sol`）** 下使用。目标项目必须已被信任，hook 也需要由用户自行审阅并信任。具体操作请让正在配置的 Codex 按你的实际环境说明。

附带文件是 `assets/developer-context.md`。其内容由用户维护和审阅；配置过程不把正文交给模型预读，正常触发 hook 时仍按要求读取并加载。

本版本不再附带固定安装脚本、平台命令或逐项界面教程。Windows、macOS 和 Linux 的具体实现均交给当前环境中的 Codex 处理；这不代表已经完成这些平台的实际运行验证。
