# codex上高速

在用户指定的项目中配置 hook，使 Codex 在用户每次提交消息时读取本技能的 `assets/developer-context.md`，并将其加载为 developer 上下文。

由执行本技能的 Codex 根据当前操作系统、客户端、已有配置和可用工具，自行决定具体实现。不要预设编程语言、解释器、shell、文件路径格式、命令或界面入口，也不要把其他系统的做法直接套用到当前环境。

保留以下要求：

- 安装和配置时不预读附带文件或项目副本的正文，不展示、总结或代替用户审阅，也不通过试运行 hook 提前读取。复制和备份文件可以正常进行；提供文件位置，由用户自行审阅。
- 保留项目已有的其他配置和 hook，只处理本技能相关内容。更新或停用时，同样根据当前环境处理。
- hook 只负责读取并加载附带文件，不增加模型、文本内容或长度检查，不因此跳过加载。
- 完成后告知用户：仅在 **5.6 Sol（`gpt-5.6-sol`）** 下使用，必须是**已信任项目**，并且还需用户**审阅并信任 hook**。这些是使用说明，不在 hook 中自行设置限制或授予信任。
- 根据用户当前实际环境，给出可操作的项目与 hook 信任步骤，并说明如何开始使用。不要套用固定平台的命令或按钮名称，也不要把配置完成说成已经实际生效。
